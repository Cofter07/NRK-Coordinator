ІНСТРУКЦІЯ ЗІ ВСТАНОВЛЕННЯ ТА ЗАПУСКУ ПРОГРАМИ
«НРК-Координатор»

1. ВСТАНОВЛЕННЯ PYTHON

2. ЗАВАНТАЖЕННЯ ФАЙЛІВ ПРОГРАМИ
   У папці проєкту мають знаходитися три файли:
   - app.py — головний файл програми та її інтерфейс;
   - nrk_core.py — основна логіка обробки даних і добору НРК;
   - robots.json — файл каталогу роботизованих комплексів.

3. ВСТАНОВЛЕННЯ НЕОБХІДНИХ БІБЛІОТЕК
Відкрийте папку, у якій знаходяться app.py, nrk_core.py та robots.json.
Клацніть по адресному рядку Провідника Windows, введіть powershell і натисніть Enter. Відкриється PowerShell саме в цій папці.
Виконайте команду створення віртуального середовища:
   python -m venv .venv
Встановіть необхідні бібліотеки командами:
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install streamlit pandas
   Дочекайтеся завершення встановлення.

4. ЗАПУСК ПРОГРАМИ
Переконайтеся, що PowerShell відкритий у папці проєкту.
Виконайте команду:
   .\.venv\Scripts\python.exe -m streamlit run app.py

Після запуску вікно термінала покаже локальну адресу програми:
   http://localhost:8501

4. Відкрийте цю адресу у браузері. Відобразиться інтерфейс «НРК-Координатор».

5. Не закривайте вікно PowerShell під час роботи програми. Щоб зупинити програму, поверніться до нього та натисніть Ctrl+C.
